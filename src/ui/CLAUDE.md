# ui: DOM-інтерфейс

Звичайний DOM поверх канваса, без фреймворку. Стан читає з симуляції, змінює його лише командами через хуки.

## Файли
- `lobby.ts`: лобі (створити кімнату, приєднатись, «Продовжити» із сейва). Стилі в рядку `CSS` всередині файла.
- `cityHud.ts` + `cityHud.css`: панель міста: верхня смуга (ресурси, швидкість), картка інформації про виділене, повідомлення. Нижня панель і вікна живуть у `windows.ts`.
- `theme.css`: тема (палітра, рамка `k-frame`, кнопки `k-btn`, вкладки `k-tab`, картки `k-card`). Нові елементи беруть лише її змінні й класи.
- `icons.ts`: лінійні SVG-іконки (`icon(name)`).
- `windows.ts`: `Section` (розділ = кнопка + вікно з вкладками) і `WindowManager` (нижня панель, відкриття, Esc).
- `sections/index.ts`: реєстр розділів (порядок = порядок кнопок). Як додати розділ: `docs/systems/ui.md`.
- `sections/build.ts`: «Будівництво» (пласке вікно, вкладки Житло / Ресурси / Настрій / Захист).
- `sections/economy.ts`: «Економіка» (вкладки Виробництво / Ресурси).
- `sections/npcs.ts`: «Жителі» (картки з фільтром, режим призначення, деталі вибраного збоку).
- `sections/inventory.ts`: «Інвентар» (ресурси; предмети й лут поки макет).
- `sections/worldMap.ts`: кнопка «Карта» (вихід на карту світу).
- `sections/settings.ts`: «Налаштування» (масштаб інтерфейсу, підказка по керуванню).
- `npcDetail.ts`: стати й перки жителя для картки (чиста функція).
- `hudTypes.ts`: `HudHooks` (дії панелі), `HudState`, `SectionCtx`.
- `rows.ts`: `syncRows`: рядки списку живуть постійно й оновлюються на місці.
- `info.ts`: що виділено (`Sel`) і тексти про це (`describeSel`), українські назви споруд, ресурсів, професій, станів.
- `names.ts`: ім'я жителя за `nameId`.
- `pacer.ts`: швидкості гри (`SPEEDS`) і відлік тіків (`TickPacer`).

## Правила
- Під мишку. Усі розміри множ на CSS-змінну `--ui` (повзунок масштабу), без фіксованих пікселів. Телефон поки не робимо, але hover не має бути єдиним способом щось зробити.
- Кнопки в панелях мають фіксовані позиції: лічильники й індикатори не зсувають розкладку.
- Тексти для гравця українською, назви тримай у `info.ts`.
- Перевірка: чисті функції тестами, поведінку панелі смоуком `scripts/smoke-ui.cjs` (клік по кнопках, стан через DOM і `window.__game`).
