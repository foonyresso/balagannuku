# ui: DOM-інтерфейс

Звичайний DOM поверх канваса, без фреймворку. Стан читає з симуляції, змінює його лише командами через хуки.

## Файли
- `lobby.ts`: лобі (створити кімнату, приєднатись, «Продовжити» із сейва). Стилі в рядку `CSS` всередині файла.
- `cityHud.ts` + `cityHud.css`: панель міста. Вкладки `build` / `people` / `prod`, список жителів, швидкість гри. Рядки списку живуть постійно й оновлюються на місці.
- `info.ts`: що виділено (`Sel`) і тексти про це (`describeSel`), українські назви споруд, ресурсів, професій, станів.
- `names.ts`: ім'я жителя за `nameId`.
- `pacer.ts`: швидкості гри (`SPEEDS`) і відлік тіків (`TickPacer`).

## Правила
- Під мишку. Усі розміри множ на CSS-змінну `--ui` (повзунок масштабу), без фіксованих пікселів. Телефон поки не робимо, але hover не має бути єдиним способом щось зробити.
- Кнопки в панелях мають фіксовані позиції: лічильники й індикатори не зсувають розкладку.
- Тексти для гравця українською, назви тримай у `info.ts`.
- Перевірка: чисті функції тестами, поведінку панелі смоуком `scripts/smoke-ui.cjs` (клік по кнопках, стан через DOM і `window.__game`).
