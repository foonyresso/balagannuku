# render/style: процедурні спрайти

Стиль «Kingdom»: кожен спрайт малює функція на 2D-canvas, усі спрайти пакуються в атласи.

## Файли
- `atlas.ts`: реєстр спрайтів. `defineSprite(...)` до першого `ensureAtlas()`, `spr(id)` дає текстуру.
- `pixel.ts`: піксельні примітиви для малювальників.
- `buildings.ts`: споруди. Додати: `registerBuildingStyle('kind', { zMax, paint(p) {...}, fx })`. Без стилю діє запасна коробка з дахом. Великий: шукай за назвою виду споруди.
- `campfire.ts`: вогнище вільних жителів (кільце каміння, дрова, полум'я, світло, дим).
- `characters.ts`: жителі, кадри ходьби й роботи. Додати клас: `CLASSES.id = {...}` і за потреби `CLASS_OF[profession]`.
- `props.ts`: дерева, каміння, кущі та їхні варіанти.
- `ground.ts`: текстура землі.
- `atmosphere.ts`: пора доби, світло, віньєтка, серпанок.
- `particles.ts`: частинки (тріски, іскри, дим, бризки).
- `index.ts`: палітра `PALETTE`, `initStyle()`, реекспорт.

## Правила
- Спрайт споруди малюється в тій самій проєкції, що й карта (`../projection.ts`): грані задаються в одиницях площини.
- Розмір споруди бери з `FOOTPRINT` (`sim/balance/buildings.ts`), не хардкодь.
- Кольори бери з палітри, нові додавай туди ж.
- `style.test.ts` перевіряє, що всі спрайти реєструються й малюються без помилок. Новий спрайт додай у нього.
