# Інтерфейс міста

Нижня панель кнопок-іконок по центру. Кнопка відкриває вікно розділу: `place: 'dock'` (пласке, над панеллю, як будівництво) або `'center'` (в центрі екрана). Відкрите одне вікно за раз, Esc закриває. Усе оформлення з `src/ui/theme.css`.

## Як додати розділ
1. Іконка: рядок у `PATHS` у `icons.ts` (за потреби).
2. Файл `src/ui/sections/<id>.ts`: об'єкт `Section` (`id`, `icon`, `title`, `place`, `tabs?`, `mount`). `mount` отримує по контейнеру на вкладку (без вкладок: `main`) й повертає функцію оновлення; вона викликається, лише поки вікно відкрите.
3. Рядок у `SECTIONS` у `sections/index.ts`. Порядок = порядок кнопок.
4. Рядок у `src/ui/CLAUDE.md`.

Дії над світом робляться через `ctx.hooks` (команди в `render/city/actions.ts`), стан читається з `ctx.w`. Тексти українською, назви в `info.ts`.

## Правила оформлення
- Вікно: `k-frame`, заголовок `k-title`, вкладки `k-tabs`/`k-tab`, картки `k-card`, кнопки `k-btn`, чипи `k-chip`, порожній стан `k-empty`. Голого тексту без картки чи рамки не лишай.
- Розміри в `em`. Вікно має вміщатися в `94vw` і `78vh`, тіло прокручується.
- Рядки списків не перебудовуй, а оновлюй на місці (`rows.ts`), клік по них слухай на `pointerdown`.
- Розділу ще без даних лишай заглушку (`k-empty`), механіки не вигадуй (див. `docs/ROADMAP.md`).
