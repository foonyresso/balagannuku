# Архітектура

Гекс-стратегія (Settlers / Anno + герої з Dungeon Village 2). Vite + TypeScript (strict) + PixiJS, кооператив 2-8 гравців через WebRTC. Сторінка збирається Cloudflare Pages з гілки `main`.

## Шари
- `src/shared/`: контракти. Типи стану, команди, сейв, мережеві повідомлення. Без залежностей.
- `src/sim/`: детермінована симуляція `(стан, команди) -> стан`. Без DOM і Pixi, запускається headless у тестах.
- `src/render/`: PixiJS, лише читає стан. Одна фіксована ізометрія (`render/projection.ts`).
- `src/ui/`: DOM-інтерфейс.
- `src/net/`: WebRTC, лобі, хост і клієнт.
- `src/persist/`: сейви.
- `src/main.ts`: зшиває все.

Залежності: `render`, `ui`, `net`, `persist` -> `shared`, `sim`; `sim` -> лише `shared`.

## Основні ідеї
- **Одне дерево стану.** Усе лежить у `GameState` (`shared/state.ts`). NPC зберігаються як SoA: паралельні typed arrays, індекс = `NpcId`. Випадковість лише з ГПВЧ із seed у стані.
- **Команди.** Стан змінюють тільки команди (`shared/commands.ts`): клієнт -> хост -> валідація -> застосування на тіку -> `CommandResult`.
- **Хост-авторитетна мережа.** Симуляцію веде хост, клієнти шлють команди й малюють отримане. Світ живе, поки хост онлайн.
- **Похідне не зберігається.** Вода, вид вузлів ресурсів, стадії стежок виводяться з seed або з трафіку. У сейві лише те, що не можна відновити.
- **Продуктивність.** SoA, один A* на подорож, груба сітка навігації поверх дрібних тайлів. Бюджет тримає `sim/bench.test.ts`.
