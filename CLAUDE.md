# Балаганники

Гекс-стратегія: Vite + TypeScript (strict) + PixiJS, кооператив через WebRTC. Коментарі, коміти й доки пишемо українською.

## Команди
- `npm run check -- --fast`: карти файлів, типи, юніт-тести без бенчмарків. Під час роботи.
- `npm run check`: те саме плюс бенчмарки, збірка й усі headless-смоуки. Перед PR, триває близько 9 хвилин. Друкує рядок на етап, вивід показує лише для провалів.
- `npm run check -- --smoke ui`: збірка й один смоук (`scripts/smoke-ui.cjs`).
- `npx vitest run src/sim/water.test.ts`: один тест-файл.

## Шари (`src/`)
| Каталог | Що там | Від чого залежить |
|---|---|---|
| `shared/` | контракти: типи стану, команди, сейв, мережеві повідомлення | ні від чого |
| `sim/` | детермінована симуляція, без DOM і Pixi | `shared` |
| `render/` | PixiJS, лише читає стан | `shared`, `sim` |
| `ui/` | DOM-інтерфейс | `shared`, `sim` |
| `net/` | WebRTC, лобі, хост і клієнт | `shared`, `sim` |
| `persist/` | сейви, IndexedDB | `shared`, `sim` |

`src/main.ts` зшиває шари: лобі, карта світу, вхід у місто, `window.__game` для headless-перевірок.

У кожному каталозі є свій `CLAUDE.md` з картою файлів і правилами. Він підвантажується сам, коли відкриваєш файл із цього каталогу. Каталоги, яких задача не стосується, не відкривай.

## Жорсткі правила
- Стан гри змінюють лише команди (`shared/commands.ts`). Симуляція детермінована: без `Math.random` і `Date`, випадковість лише з `sim/rng.ts`.
- Зміна форми `SerializedGameState` вимагає підняти `SAVE_VERSION` і додати міграцію. Зміна мережевих повідомлень вимагає підняти `NET_PROTOCOL_VERSION`.
- Камера скрізь одна: фіксована ізометрія без повороту, лише пан і зум. Усі перетворення координат живуть у `render/projection.ts`.
- Ресурси безкінечні, джерела не вичерпуються.
- Числа балансу лежать у `sim/balance/`, а не в логіці. Споруда — один запис у таблиці `BUILDINGS`.
- Інтерфейс під мишку, масштабується повзунком (`--ui` у CSS). Телефон поки не робимо, але шлях до нього не закриваємо.
- Логіку перевіряй кодом: тести, смоуки, стан через `window.__game` і DOM. Скріншотів не роби.

## Як не роздувати контекст
- Код розкладено по малих файлах за темами: поведінка працівників у `sim/jobs/`, системи світу в `sim/systems/`, вигляд міста в `render/city/`. Знайди потрібний файл у карті `CLAUDE.md` каталогу й читай лише його.
- Нову логіку клади в новий файл поруч. У збирачах (`sim/step.ts`, `sim/jobs/npc.ts`, `render/city/view.ts`) додавай лише рядок виклику. Файл понад 250 рядків діли за темами.
- `package-lock.json`, `dist/` і `node_modules/` не читай.
- Додав файл у `src/`: додай рядок у `CLAUDE.md` цього каталогу (це перевіряє `npm run check`).
- У доках не дублюй числа з коду, називай константу. Змінив поведінку системи: онови її файл у `docs/systems/`.
