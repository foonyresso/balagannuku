# scripts: перевірки

`check.cjs` запускає все й сам піднімає сервери. Окремо смоуки руками не запускай: `npm run check -- --smoke <ім'я>`.

## Смоуки (headless Chromium, Playwright уже встановлений глобально)
- `smoke.cjs`: кнопки лобі клікаються, консоль без помилок.
- `smoke-solo.cjs`: карта -> вибір сектора -> «Грати» -> місто.
- `smoke-host.cjs`: те саме через лобі з кімнатою. Потребує справжнього сервера PeerJS.
- `smoke-ui.cjs`: панель міста. Будівництво, вибір, інформація про об'єкти, стеження камери.
- `smoke-pause.cjs`: пауза лісопильні.
- `smoke-save.cjs`: автосейв, файл, «Продовжити», несумісний сейв. PeerJS замокано, іде на dev-сервері.
- `smoke-style.cjs`: спрайти (силует, кадри ходьби, якорі споруд). Імпортує сирці, тому йде на dev-сервері.
- `smoke-style-city.cjs`: місто з усіма спорудами, світло, частинки, зміна пори доби.

## Новий смоук
- Назва `smoke-<тема>.cjs`, `check.cjs` підхопить сам.
- Адресу бери з `process.env.URL`.
- Стан гри читай через `window.__game` і DOM. Скріншотів не роби.
- Друкуй коротко: рядок на перевірку (`ok` / `FAIL`), а не дампи стану.
- Коди виходу: 0 успіх, 1 провал, 2 бракує зовнішньої мережі (`check.cjs` покаже `skip`).
- Мережу мокай (приклад у `smoke-save.cjs`), щоб смоук не залежав від PeerJS.
- Типово смоук іде на `vite preview` (збірка). Якщо він імпортує `/src/...` або мокає модуль за URL, додай угорі рядок `// check: dev`, і `check.cjs` запустить його на dev-сервері.
